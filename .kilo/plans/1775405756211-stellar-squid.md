# Plan: Remove deprecated `images.domains` from next.config.js

## Problem

`next.config.js` contains the deprecated `images.domains` alongside `images.remotePatterns`. The `domains` array is redundant since `remotePatterns` already covers the same hostname (`render.worldofwarcraft.com`) with stricter matching (protocol + pathname).

## Fix

Remove the `domains` key from the `images` config in `next.config.js`. The `remotePatterns` array already covers the same domain:

```js
images: {
  remotePatterns: [
    {
      protocol: 'https',
      hostname: 'render.worldofwarcraft.com',
      pathname: '/**',
    },
  ],
},
```

## Files to edit

- `next.config.js` — remove `domains: ['render.worldofwarcraft.com'],` line

## Verification

- Run `pnpm build` — deprecation warning should be gone, build still passes
